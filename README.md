# Astro + Tailwind Golden Path 🚀

A minimal **Astro + TailwindCSS** starter.  
This repo is designed as a Golden Path starter for building blogs, docs, or landing pages with modern styling.

## ✨ Features
- ⚡ Astro static site generator
- 🎨 TailwindCSS 3
- 🔥 Ready-to-deploy on Vercel or Netlify
- 📦 TypeScript support

## 🛠 Commands
```bash
npm install
npm run dev   # start dev server
npm run build # build for production
npm run preview
